# Pefrien 本地前后端

运行 `python server.py --port 8767`，访问 http://127.0.0.1:8767/ 。依赖 Python 3.10+，仅使用标准库；不需要安装第三方后端包。

## 当前能力

- 手机号 + 本地验证码注册/登录，HttpOnly 会话 cookie 自动登录，30 天有效。验证码随机生成、5 分钟过期、5 次错误失效、60 秒重发间隔；不会发送真实短信。
- SQLite 账户、宠物档案/照片、距离设置、相遇、喜欢、黑名单、反馈持久存储。资料自动同步，版本冲突时要求选择保留哪份，防止跨设备互相覆盖。草稿按账户隔离；原匿名草稿只在用户确认后导入。
- 喜欢的狗狗匹配权重为 3，普通候选为 1；距离与双方全部出门小狗的偏好仍优先过滤。拉黑为账号双向排除，覆盖该狗友的全部小狗。
- 滚动 30 天不同账号的拉黑次数：3 次提醒；5 次停用匹配 24 小时，同一 30 天不重复延长；10 次永久停用匹配。首个拉黑不扣分，从第 2 次起每次扣 5 分；窗口过期恢复行为分，永久停用不自动恢复。反馈/登录不受匹配停用限制。同一账号解除后重复拉黑不重复计数，只有已完成相遇才能评价。
- 距离默认 2 km，可选 500 m/1/2/3/5 km/5 km+；本地使用示例距离（5 km+ 上限 20 km）和示例路线，尚无 GPS/真实导航。
- 访客也能反馈；登录账号可查看自己反馈的处理状态及回复。

## 运营后台

http://127.0.0.1:8767/ops.html 。首次启动自动生成 `.runtime/ops-key.txt`，在页面输入该密钥即可查看反馈、填写回复、标记处理状态。密钥只在运营页内存中保留。

数据库位于 `.runtime/pefrien.sqlite3`，不在静态服务目录 `dist/` 中；整个 `.runtime/` 被 git 忽略。备份数据库即可保留本地账户资料。

## 真实服务接入边界

当前服务只绑定本机 127.0.0.1，测试验证码会在登录页显示，**不能直接作为公开生产登录服务**。微信、QQ、支付宝入口已提供；未配置时明确告知用户，不模拟成功，不收集第三方密码。`auth_adapters.py` 列出服务端适配边界和所需配置。

上线前需配置短信供应商与三个开放平台应用、注册回调地址，实现服务端授权码交换/平台签名校验/state 与 nonce 防重放，并将 `(provider, subject)` 绑定到统一账户。手机号绑定合并须再次验证，不能凭客户端 openid 或相同昵称合并。

真实跨设备同步需要将同一后端部署到可访问的 HTTPS 域名，并使用 Secure cookies、正式登录和数据库备份。目前仅是访问同一个本地服务的两个浏览器共享账户，后端尚未发布公网；GitHub 仓库仅保存源码并提供静态前端预览。GitHub Pages 本身不能运行这个 Python/SQLite 服务。

前端入口 `index.html` / `accounts.js` / `accounts.css`；`dist/` 是服务器实际提供的网页文件。每次改前端后需同步相应文件到 dist。
