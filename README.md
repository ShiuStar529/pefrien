# Pefrien

一款手机端盲盒遛狗网页应用：为家里的小狗建立档案，用会嗅嗅的狗鼻子寻找新朋友。

[GitHub Pages 前端预览](https://shiustar529.github.io/pefrien/)

## 当前发布范围

仓库包含前端和本地 Python / SQLite 后端源码。GitHub Pages 从 `main` 根目录发布静态前端，**不能运行后端**；在线预览已提供浏览器本地演示模式：手机号 `15012345678` 配任意非空验证码即可体验。演示资料、照片、喜欢和拉黑仅保存在当前浏览器，反馈不会发送给运营，狗友与路线都是示例。真实登录、跨设备同步与真实匹配需要后续部署后端。

## 本地运行

需要 Python 3.10 或更新版本，无第三方依赖。在仓库根目录运行：

```sh
python server.py --port 8767
```

打开 http://127.0.0.1:8767/ 。本地服务只监听本机，实际静态文件目录是 `dist/`。

手机号注册使用页面显示的本地测试验证码，不会发送短信。微信、QQ、支付宝入口已预留，正式授权服务尚未接入。本地账户资料存入 `.runtime/`，该目录和运营密钥不会提交到仓库。

## 已有功能

- 多狗家庭档案、可选照片、品种模糊搜索、交友偏好与自动保存。
- 五种狗鼻子导航形象，自动嗅嗅和点击动效，默认边牧。
- 本地注册、自动登录、账户绑定资料、同步冲突处理。
- 默认 2 km 的距离选择、偏好匹配、喜欢加权与双向拉黑。
- 滚动 30 天拉黑计数：3 次提醒、5 次停用匹配一天、10 次永久停用匹配。
- 用户反馈与受密钥保护的本地运营回复页面。
- 首页插画为 960 px 宽 WebP，约 39 KB。

匹配距离、路线和附近狗友目前使用演示数据。生产登录、真实定位导航和公网后端尚未部署。
